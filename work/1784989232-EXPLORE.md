### 2.1 The dictionary: two-linear-form correlations **are** AP-restricted shift correlations

> **Proposition D1.** For integers \(a\ge1\), \(b\ge1\) and \(y\ge1\), exactly:
> \[
>   \sum_{m\le y}\lambda(m)\lambda(am+b)\;=\;\lambda(a)\!\!\sum_{N\le ay,\ a\mid N}\!\!\lambda(N)\lambda(N+b).
> \]

*Proof.* \(\lambda(am)\lambda(am+b)=\lambda(a)\lambda(m)\lambda(am+b)\); multiply by
\(\lambda(a)\) and substitute \(N=am\), a bijection from \(m\le y\) onto the multiples of \(a\)
up to \(ay\). \(\square\) (**V7**: 6 parameter sets, exact integer equality.)

Conversely, for the principal class,
\(\sum_{n\le x,D\mid n}\lambda(n)\lambda(n+h)=\lambda(D)\lambda(g)\sum_{m\le x/D}\lambda(m)\lambda(D'm+h')\)
with \(g=\gcd(D,h)\), \(D'=D/g\), \(h'=h/g\). **So the class of "correlations of two distinct
linear forms" and the class of "AP-restricted shift correlations at the principal class" are
the same class.** DISTILL's targets (i) and (ii) are therefore not two problems but one.

### 2.4 Why \(h/D\in\mathbb Z\) is exactly what the mechanism eats: a connectivity dichotomy

> **Proposition D4.** Let \(G(a,D,h)\) be the graph on \([1,x]\cap\mathbb Z\) with edges
> \(\{n,n+h\}\) for \(n\equiv a\ (\mathrm{mod}\ D)\), \(n+h\le x\). Then
> * if \(D\mid h\): \(G\) is a disjoint union of **paths with \(\asymp x/h\) vertices** (all
>   vertices of a path lie in the class \(a\));
> * if \(D\nmid h\): \(G\) is a **perfect matching** between the classes \(a\) and \(a+h\)
>   (mod \(D\)) plus isolated vertices; **every component has \(\le2\) vertices.**

*Proof.* A vertex \(n\) has an edge to \(n+h\) iff \(n\equiv a\), and to \(n-h\) iff
\(n\equiv a+h\). If \(D\mid h\) these two conditions coincide and each vertex of the class has
both, giving paths \(n,n+h,n+2h,\dots\). If \(D\nmid h\) then \(a\not\equiv a+h\), so each
vertex satisfies at most one of them: degree \(\le1\). \(\square\)
(**V8**: union-find at 12 parameter sets — max component \(600,300,300,\dots\) when \(D\mid h\);
max component **exactly 2** at \((0,2,1),(1,2,1),(0,3,2),(1,3,2),(0,4,2),(2,4,2)\).)

### 2.5 The matching case is not empty: exact rigidity, and the missing robust version

> **Lemma R (exact rigidity).** Let \(f:\mathbb N\to\{\pm1\}\) be completely multiplicative
> with \(f(2m)f(2m+1)=\sigma\) for **all** \(m\ge1\), \(\sigma\in\{\pm1\}\) fixed. Then
> \(\sigma=+1\) and \(f\equiv1\).

*Proof.* Write \(\varepsilon=f(2)\), so \(f(2m)=\varepsilon f(m)\) and the hypothesis is
\(f(2m+1)=\sigma\varepsilon f(m)\). \(m=1\): \(f(3)=\sigma\varepsilon\). \(m=2\):
\(f(5)=\sigma\varepsilon^2=\sigma\). \(m=3\): \(f(7)=\sigma\varepsilon\cdot\sigma\varepsilon=1\).
\(m=4\): \(f(9)=f(3)^2=1\) must equal \(\sigma\varepsilon f(4)=\sigma\varepsilon\), so
\(\sigma\varepsilon=1\), hence \(f(2m+1)=f(m)\) for all \(m\), \(f(3)=1\), \(f(5)=\varepsilon\),
\(f(7)=1\). \(m=7\): \(f(15)=f(7)=1\) while \(f(15)=f(3)f(5)=\varepsilon\), so
\(\varepsilon=1\) and \(\sigma=1\). Now \(f(2k)=f(k)\) and \(f(2k+1)=f(k)\) for all \(k\), so by
strong induction from \(f(1)=1\), \(f\equiv1\). \(\square\)
(**V9**: brute force over all \(2^{11}=2048\) sign assignments on the primes \(\le31\), testing
\(m=1,\dots,15\) — exactly **1** survivor for \(\sigma=+1\) (the all-\(+1\) assignment) and
**0** for \(\sigma=-1\).)

Since \(\lambda(2)=-1\), \(\lambda\) is not the survivor: **the exact extremal case of the
even-class shift-1 correlation is impossible by pure multiplicativity, with no analytic input
at all.** What is missing is only *robustness*: an implication of the form

> **[TARGET-ROB]** *If a completely multiplicative \(f:\mathbb N\to\{\pm1\}\) satisfies
> \(f(2m)f(2m+1)=\sigma\) for all \(m\le y\) outside a set of size \(\varepsilon y\), then \(f\)
> pretends to be \(1\) (or: \(\sum_{n\le y}f(n)\gg_\varepsilon y\)).*

A quantitative [TARGET-ROB] would give a nontrivial Cesàro bound at \((a,d)=(0,4)\) and
\((2,4)\) — i.e. the first moduli beyond \(\{1,2\}\) — by D2. **This is a target of a shape the
project has not previously attempted: approximate rigidity for a multiplicative functional
equation, rather than cancellation in short intervals.** It is the natural escalation of the
wall in D4′, because it attacks exactly the resource D4′ says the matching case lacks. I do
**not** claim it; I name it, and I state honestly that Lemma R's proof is a chain of *exact*
evaluations (\(f(9)\), \(f(15)\)) at fixed integers, so it is exactly the kind of argument that
a density-\(\varepsilon\) exceptional set destroys, and no route to robustifying it is in hand.

### 2.6 A sharp threshold that makes [C5C-EFF] load-bearing

> **Proposition D5.** With \(c\) as in [C5C-MRT] and \(\delta_1\) as in [C5C-SH1], the existing
> constant-factor route gives a **nontrivial** bound on the odd class
> \(\sum_{n\le x,\,2\nmid n}\lambda(n)\lambda(n+2)\) **iff**
> \[
>   1-8c\;<\;\frac{\delta_1}{2}\qquad\Longleftrightarrow\qquad c\;>\;\frac18-\frac{\delta_1}{16}.
> \]

*Proof.* \(\Sigma_{\rm odd}=S_2(x)-\Sigma_{\rm even}=S_2(x)-S_1(x/2)\) by [C5C-ID2], so
\(|\Sigma_{\rm odd}|\le(1-8c)x+(1-\delta_1)\frac x2\); this beats the trivial \(x/2\) iff
\((1-8c)x<\delta_1x/2\). \(\square\) (**V13**: the threshold flips exactly there.)

Because \(c\le1/8\) always, D5 says the odd class is reachable **iff the eight length-3
densities are within \(\delta_1/2\) of uniform**. That is a knife-edge no current method
approaches — but it converts [C5C-EFF] from a bookkeeping node into the node that decides a
concrete \((a,d)\) pair. **I therefore keep [C5C-EFF] OPEN and mark it load-bearing.**

### 2.7 Verdict on the two targets, and what I did not find

* **Target (ii) (Cesàro sign patterns for \((\lambda(m),\lambda(2m+1)))\)**: *not* more
  reachable. By D2 it **is** the parity split of MR's own theorem; by D3/D4 no dilation
  escapes the matching regime; by D4′ MR's short-interval input is consistent with both
  extremal hypotheses. The one thing that *does* bite is Lemma R, and only exactly.
* **Target (i) (AP-restricted sign patterns, uniform in \(d\))**: sits on the same side of the
  same dichotomy for every \(D\ge3\) at \(h=2\), so it inherits D4′ verbatim. I also checked
  the nearest literature: **Klurman–Mangerel–Teräväinen, *Multiplicative functions in short
  arithmetic progressions*, Proc. LMS 127 (2023) 366–446 (arXiv:1909.12280)** — search-level
  verification of the bibliographic data plus abstract summary — proves smallness of the
  **variance over residue classes \(a\) for almost all moduli \(q\)** (a Barban–Davenport–
  Halberstam-type statement, with an exceptional set of \(q\), and every-\(q\) only under GRH).
  That is *average over \(a\)* and *almost all \(q\)*; C5 needs **all** \(a\) and **all**
  \(q\le x^{1-\varepsilon}\). **It does not supply target (i)**, and I did not open its full
  text. Recorded as a literature fact at abstract level, not built upon.
* **What I did not find:** any Cesàro (non-logarithmic) sign-pattern theorem for two distinct
  linear forms; any AP-restricted MR theorem uniform in the modulus. I decline to assert
  either their existence or their absence.

### 2.8 Where this leaves the escalation

The wall is now stated at its sharpest so far, and it is *not* the parity barrier in the
abstract — it is a concrete resource:

> **The only proven parity-breaking mechanism for two-point correlations converts a
> correlation hypothesis into a statement about \(\lambda\) on a connected run, and the
> shift graph of the twin-prime datum restricted to any modulus \(D\ge3\) has no runs — it is
> a matching, and \(h/D=2/D\notin\mathbb Z\) is invariant under every dilation.**

Two escalation routes are now named and neither is a relocation of C5:
* **[TARGET-ROB]** (§2.5) — robust rigidity for the functional equation \(f(2m)f(2m+1)=\sigma\).
  Attacks the matching case directly; exact case already proved (Lemma R).
* **[TARGET-CONN]** — find or rule out a *different* connectivity: a graph on \([1,x]\) whose
  edges respect a fixed residue class mod \(D\), whose components are long, and along which a
  correlation hypothesis propagates. By D4 the shift graph itself never works; the question is
  whether a *composite* move (e.g. alternating \(n\mapsto n+h\) with \(n\mapsto tn\)) generates
  long components inside a class while keeping the correlation hypothesis meaningful. This is
  a well-posed graph-theoretic question that has not been asked in this project.

> **(a)** (Prop D4) The graph on \([1,x]\) with edges \(\{n,n+h\}\), \(n\equiv a\ (D)\), has all
> components of size \(\le2\) if \(D\nmid h\), and is a union of paths with \(\asymp x/h\)
> vertices if \(D\mid h\).
> **(b)** (Prop D3) The dilation moves (U) \((D,h)\mapsto(tD,th)\) and (Dn)
> \((D,h)\mapsto(D/g,h/g)\) both preserve \(h/D\in\mathbb Q\); hence \(D\mid h\) is invariant,
> and for \(h=2\) the invariant class \(\{D:D\mid h\}=\{1,2\}\).
> **(c)** (Prop D2) Exactly:
> \(\sum_{n\le x,4\mid n}\lambda(n)\lambda(n+2)=\sum_{n\le x/2,2\mid n}\lambda(n)\lambda(n+1)
> =-\sum_{m\le x/4}\lambda(m)\lambda(2m+1)\), and \(n\equiv2\,(4)\) gives the odd half.
> **(d)** *(scoped, mechanism-specific)* The MR "extremal correlation \(\Rightarrow\) \(\lambda\)
> constant on a run \(\Rightarrow\) \(|\sum_I\lambda|\gg H\) contradicting MR" step is available
> only in the path case; in the matching case at \((a,D,h)=(0,2,1)\) it yields
> \(\sum_{n\in I}\lambda=-(1+\sigma)\sum_{m\in I/2}\lambda+O(\varepsilon H)\), with which MR is
> consistent for both \(\sigma\).
> **(e)** (Lemma R) The only completely multiplicative \(f:\mathbb N\to\{\pm1\}\) with
> \(f(2m)f(2m+1)=\sigma\) for all \(m\) is \(f\equiv1\), \(\sigma=+1\); \(\lambda\) is not it.

*Already checked:* (a) proved (degree \(\le1\) when \(a\not\equiv a+h\)) and verified by
union-find at 12 parameter sets; (b) one-line invariance, and (U)/(Dn) themselves verified
exactly (V2, V7); (c) verified to integer equality at 5 and 4 values of \(x\) up to \(10^7\);
(e) proved by hand and confirmed by brute force over \(2^{11}\) assignments.
*What I want stress-tested:* (i) **is (b)'s move set actually exhaustive** for what complete
multiplicativity provides — is there a legitimate move that changes \(h/D\) (e.g. one using a
