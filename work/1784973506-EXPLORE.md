## Part 2 — `L-G12-2 [LOCAL-CLOSED]` — **TRUE**

*For odd `p`, `A_p = M_p + M'_p − 1`, where `M_p(z,y) = (1−1/p)^{1−z}(1−1/p²)^{−y}` is the local mean.
Equivalently* `σ_p = 1 − (1 − 1/M_p)(1 − 1/M'_p)`.

*Proof.* `M_p(f) = Σ_a f(p^a)(p^{−a} − p^{−a−1}) = (1−1/p) F_p(1/p)`, which gives the stated closed form.
For odd `p` at most one of `n, n+2` is divisible by `p`, so

    A_p = (1−2/p)·1 + Σ_{a≥1}(p^{−a}−p^{−a−1})[g(p^a) + g'(p^a)]
        = (1−2/p) − 2(1−1/p) + M_p + M'_p .

The constant collapses: `(1−2/p) − 2(1−1/p) = 1 − 2/p − 2 + 2/p = −1`. ∎
Dividing by `M_p M'_p` gives the `σ_p` form. **`p = 2` is genuinely exceptional** and is *not* covered:
there `v₂(n) ≥ 2 ⟹ v₂(n+2) = 1` and `v₂(n+2) ≥ 2 ⟹ v₂(n) = 1`, giving
`A_2 = ½ + Σ_{a≥2} 2^{−a−1}[g(2^a)g'(2) + g(2)g'(2^a)]`.

**Sanity consequence, checked:** if either function is `≡ 1` then `M ≡ 1` and `σ_p ≡ 1`, so `𝔖 = 1`
identically — confirmed to 12 places at `(1,0 ; 1,0)` and `(1,0 ; −1,1)`.

**Specializations, each matching an independent known constant:**

## Part 3 — `L-G12-3 [SS-ENTIRE-4]` — **TRUE. This answers T20: YES.**

*`𝔖` is entire on `ℂ⁴`.*

*Proof.* Uniformly on `|z|,|y|,|z'|,|y'| ≤ R`,

    1/M_p = (1−1/p)^{z−1}(1−1/p²)^{y} = 1 − (z−1)/p + O_R(1/p²),

so `1 − 1/M_p = (z−1)/p + O_R(1/p²)` and therefore

    σ_p − 1 = −(z−1)(z'−1)/p² + O_R(1/p³).

Hence `Σ_p |σ_p − 1| < ∞` locally uniformly, the Euler product converges locally uniformly to an entire
function of four variables, and `(−1,1;−1,1)` is an ordinary interior point. ∎

**Audit** (Part 5): `p² · max_{box}|σ_p − 1|` against the predicted limit `(R+1)²`:

```
   R = 1 :  p=1009 -> 4.0159    p=10007 -> 4.0016    p=100003 -> 4.0002    (limit 4)
   R = 2 :  p=1009 -> 9.0477    p=10007 -> 9.0048    p=100003 -> 9.0005    (limit 9)
   R = 3 :  p=1009 -> 16.1035   p=10007 -> 16.0104   p=100003 -> 16.0010   (limit 16)
```

**`[SS-ENTIRE]` therefore UPGRADES exactly as pre-registered:** it is no longer a statement about `d_z`
cousins but about **C5's own coordinates**. No natural boundary, no "parity divisor", no singularity of any
kind can be extracted from the singular series of the natural deformation family containing λ.

**RIDER — and this is the honest reason the answer was cheap.** The bound is governed by `(z−1)(z'−1)`;

is precisely the direction the singular series is least sensitive to.** The enlargement reaches the crux

## Part 4 — `L-G12-4 [LAMBDA-ZERO]` — **TRUE, then DEFLATED by its own test**

At λ's coordinates `M_p = (p−1)/(p+1)`, so `1 − 1/M_p = −2/(p−1)` and

    σ_p = 1 − 4/(p−1)²   (odd p),      σ_2 = 3,      A_p = (p−3)/(p+1).

`σ_p = 0` **iff `(p−1)² = 4` iff `p = 3`**. So `𝔖(λ,λ) = 0`, and the zero is carried by the single
local factor at `p = 3`, where the 3-adic local average of `λ(n)λ(n+2)` is **exactly** zero:

    A_3 = 1/3 + 2·Σ_{a≥1} 2·3^{−a−1}(−1)^a = 1/3 + 4·(−1/12) = 0.

This looked, for about ten minutes, like the most interesting thing in the step. **It is not, and the
deflation is decisive.** For odd `p ∤ h` the joint `p`-adic distribution of `(v_p(n), v_p(n+h))` does not
depend on `h` at all, so `A_p` is the *same* for every such shift. Brute-force enumeration over `n mod p^K`
— an entirely independent computation from the closed forms above — confirms it:

```
  p=3:  h = 2, 4, 8, 10, 14  (3 { h)  ->  A_3 = -6.3e-07 +- 1.3e-06   [ = 0 ]
        h = 6, 12            (3 | h)  ->  A_3 = +0.666667
  p=5:  h = 2,4,6,8,12,14    (5 { h)  ->  A_5 = +0.333333  = (5-3)/(5+1)
  p=7:  h = 2,...,12         (7 { h)  ->  A_7 = +0.500000  = (7-3)/(7+1)
```

**Therefore the vanishing tracks `3 ∤ h`, not the twin structure.** It holds for shifts 4, 8, 10, 14 exactly
as it does for 2, and fails for 6 and 12. It carries **no information whatsoever about `h = 2`**, and cannot
be a handle on TPC. Recorded because it is true, and because the temptation to read it as significant was
real. (It is also over-determined: at `z = −1` the Selberg–Delange normalisation already carries
`1/Γ(−1)² = 0`, so the predicted main term is `0` twice over, for two unrelated reasons, and neither
carries rate information — which is all Chowla says anyway.)
