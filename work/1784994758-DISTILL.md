## ATTACK 1 (the highest-value one, run first) — DOES δ DEGRADE WITH THE SUPPORT?

**The attack, stated as a would-be kill.** [L-SUPP-QUANT] needs δ > 1/(2p) for
f supported on (n,2p)=1. If MR's δ shrinks with the support — say like the support density, or
worse — the inequality could be self-defeating for every p and EXPLORE's "room" table (computed
with one conjectural δ held fixed across supports) would be measuring the wrong thing.

**What the primary text shows.** Read the chain: the f-dependence enters at exactly **two** places
and nowhere else.

| ingredient | f-dependence |
|---|---|
| Theorem 2 (`th:ThminS`) error `≪ (log h)^{1/3}/P_1^{1/6-η} + (log X)^{-1/50}` | **NONE.** Uniform over all multiplicative f: ℕ→[−1,1] |
| Theorem 1 (`thm:main`) error and exceptional set | **NONE.** C, C′ absolute; C′=20000 |
| the set 𝒮 | **NONE.** depends on X, η, [P_j,Q_j] only |
| the long-average lower bound `Σ_{n≤X,n∈𝒮}(|f|−f) ≫ X` | **YES**, via `dens(supp f)` and via **p₀^ν** |
| the fundamental lemma of the sieve | via the same two |

`c₁(f) := 2·dens{n : p₀∤n, f(n)≠0} / p₀^ν`, `p₀^ν` = least prime power with `f(p₀^ν) = −1`.

### 4.2 "A bound at modulus 2p" is the WRONG description — mandatory scope note

E_p is a union of **p − 2 of the 2p residue classes mod 2p**. Bounding a union of classes is
**not** bounding any class. Concretely: the result gives a non-trivial bound on **no single
residue class mod d for any d ≥ 3**. The correct sentence is: *the reached index set at shift 2 is
no longer measurable with respect to the σ-algebra generated by the classes mod 2* — a real but
very weak statement — **not** "modulus 2p reached".

### 4.3 It is NOT established to beat [G6] + a trivial estimate

`|Σ_{E_p}| ≤ |Σ_{odds}| + |Σ_{odds∖E_p}| ≤ (1/2 − 2δ_odd)x + (1/p)x` for free. Comparing with
(1/2 − 2·min δᵢ)x, **[L-SUPP-QUANT] is strictly better iff min(δ₁^{(p)}, δ₂^{(p)}) > δ_odd − 1/(2p)**.
Both constants come from the same machinery with nearly equal c₁, so this is *plausible*;
plausibility is not an audit. **Recorded as an unproven sub-claim.**

## WHAT WOULD BREAK OR ESCALATE THE CRUX

[D10] is a wall, and a wall is a checkpoint. Two things would move it:

1. **Break it inside the mechanism.** [D10] shows a single-class target needs λ·1_S to
   *anti-correlate* — more sign changes than independence predicts. That is a statement about
   λ on a valuation-defined set, and it is *false* under Chowla, so it cannot be the route.
   The escape must therefore come from **composition** (which is exactly what [D11]'s
   counterexample shows is strictly more powerful than direct application) — i.e. from *exact
   identities* between class-restricted correlations, whose invariant theory is [G3]. **The
   precise open question: is the composite closure of {MR Cor 3 applied to any single
   multiplicative f} under the exact-identity moves of [G3]/[G4] larger than {1,2}?** [G14]'s
   "nothing more" half is exactly this and stays OPEN.
2. **Escalate out of it.** [D10] is a theorem about supports of multiplicative functions, i.e.
   about *valuation-defined* subsets of ℕ. Every set that a single residue class mod d ≥ 3
   requires is *character-defined*, not valuation-defined. The missing input is a mechanism whose
   admissible test sets are character-defined — which is precisely what MR's own remark about
   non-n^{it}-pretentious **complex** f gestures at, and precisely what a cohomological reframing
   ([C7]/[C-COH-MON]) would have to supply: a trace formula whose weights are characters rather
   than supports. That remains a programme, not a step.
