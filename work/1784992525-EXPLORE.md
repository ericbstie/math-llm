### 3.1 Candidate lemma **[L-SUPP-CLASS]** — the reach of the mechanism at unquantified δ

**Setup.** f : ℕ → ℝ multiplicative, S = supp f = {n : f(n) ≠ 0}. Since f(1)=1 and f is
multiplicative, S = {n : v_p(n) ∈ S_p for every p} with S_p := {k ≥ 0 : f(p^k) ≠ 0} ∋ 0.
Put α_p := dens{n : v_p(n) ∈ S_p} = (1 − 1/p)·Σ_{k∈S_p} p^{−k} ≥ 1 − 1/p, and σ := dens S = ∏_p α_p
(σ > 0 ⟺ Σ_p (1 − α_p) < ∞).

> **Lemma A.** For every prime p and every j ≥ 1 with p ∤ j,
> dens{n : v_p(n) ∈ S_p and v_p(n+j) ∈ S_p} = **2α_p − 1**.
> *Proof.* p divides at most one of n, n+j. Split: P(p∤n, p∤n+j) = 1 − 2/p; P(p|n, v_p(n)∈S_p, p∤n+j)
> = α_p − (1 − 1/p); same with the roles swapped. Sum = 2α_p − 1. ∎
> (Verified numerically at six (p, S_p, j) including non-completely-multiplicative S_p: V5.)

> **Lemma B.** If σ > 0 then dens(S ∩ (S−2)) ≥ ½·∏_{p odd}(2α_p − 1) > 0.
> *Proof.* Independence across p by CRT (finite truncation; the tail is controlled by σ > 0).
> For odd p apply Lemma A with j = 2. For p = 2: if n is odd so is n+2 and v₂ = 0 ∈ S₂, so the
> p = 2 factor is ≥ ½. For odd p, α_p ≥ 1 − 1/p ≥ 2/3, so 2α_p − 1 ≥ 1 − 2/p > 0; and
> Σ_p (1 − (2α_p − 1)) = 2Σ_p(1 − α_p) < ∞, so the product converges to a positive limit. ∎
>
> **Corollary.** A positive proportion of the consecutive gaps of S are ≤ 2. Hence **for no h ≥ 3
> can all but o(x) of the consecutive gaps of S equal h.**

> **Lemma C.** If all but o(x) of the consecutive gaps of S ∩ [1,x] equal 2, then **S = the odd
> numbers, exactly**. If all but o(x) equal 1, then **S = ℕ**.
> *Proof (h=2).* "Almost all gaps 2" ⟹ dens(S ∩ (S−1)) = 0. By Lemma A with j = 1, that density is
> ∏_p (2α_p − 1); for odd p the factor is ≥ 1 − 2/p > 0, so the p = 2 factor must vanish:
> 2α₂ − 1 = 0, i.e. α₂ = ½, i.e. S₂ = {0}, i.e. S ⊆ odds. Then σ ≤ ½; but almost all gaps 2 forces
> σ = ½, so ∏_{p odd} α_p = 1, so α_p = 1 and S_p = ℤ_{≥0} for every odd p, i.e. S = odds.
> *(h=1).* Almost all gaps 1 forces σ = 1, so every α_p = 1 and S = ℕ. ∎

> **[L-SUPP-CLASS] (the classification).** Call a deduction from MR Corollary 3 **δ-oblivious** if
> it uses only "#signchanges(f,[1,x]) ≥ δ(f)·x for some δ(f) > 0" and is valid for every
> arbitrarily small value of δ(f). Then the *only* data
> (shift h, class a mod D) at which a δ-oblivious deduction yields a positive-proportion lower
> bound on #{n ≤ x, n ≡ a (D) : λ(n)λ(n+h) = ε} are
> **(h, a mod D) = (1, everything) and (2, the odd numbers)** — i.e. exactly MR Corollary 2 at
> h = 1 and exactly [G6].
> *Proof.* Write X_{h'} for the number of sign changes occurring at consecutive pairs of S at gap
> h', and G_{h'} for the number of such pairs. MR gives Σ_{h'} X_{h'} ≥ δx and X_{h'} ≤ G_{h'}, so
> X_h ≥ δx − Σ_{h'≠h} G_{h'}. Since δ is not quantified, this is a positive-proportion bound for
> every admissible δ **iff** Σ_{h'≠h} G_{h'} = o(x), i.e. iff almost all gaps of S equal h. By the
> Corollary to Lemma B, h ≤ 2; by Lemma C, S = ℕ (h=1) or S = odds (h=2); and in the latter case
> the gap-2 pairs are *all* odd n, so the class is the full odd class (D | 2). ∎

### 3.2 Candidate lemma **[L-SUPP-QUANT]** — the escalation: modulus 2p, conditional on a *number*

Fix an odd prime p. Let S = {n : (n, 2p) = 1}, and
* f₁ = λ·1_{(n,2p)=1} (λ × the principal character mod 2p);
* f₂ = λ·χ₋₄·1_{(n,p)=1} (λ × χ₋₄ × the principal character mod p).

Both are completely multiplicative, real, with supp = S of density σ = ½(1 − 1/p) > 0, and both
take a negative value (f₁(3) = −1 for p ≠ 3, else f₁(5) = −1; f₂(5) = −1 for p ≠ 5, else
f₂(13) = −1). So MR Cor 3 applies to both: #signchanges(fᵢ) ≥ δᵢ x.

Consecutive pairs of S: gap 2 exactly when n and n+2 are both coprime to 2p, gap ≥ 4 otherwise.
Exactly (all densities exact, V7/V8):
* gap-2 pair set **E_p := {n odd : n ≢ 0 and n ≢ −2 (mod p)}**, density G₂ = ½(1 − 2/p);
* all other pairs: density γ = σ − G₂ = **1/(2p)**.

χ₋₄(n)χ₋₄(n+2) = −1 for every odd n, so on E_p a sign change of f₁ means λ(n)λ(n+2) = −1 and a
sign change of f₂ means λ(n)λ(n+2) = +1. Therefore, with B_p, A_p the two counts on E_p,

  A_p ≥ (δ₂ − 1/(2p))x,  B_p ≥ (δ₁ − 1/(2p))x,  A_p + B_p = ½(1 − 2/p)x + O(1),

> **[L-SUPP-QUANT].** For every odd prime p, **if** min(δ₁, δ₂) > 1/(2p), **then**
> \[
>   \Bigl|\sum_{\substack{n\le x,\ n\ \mathrm{odd}\\ n\not\equiv0,\,-2\ (p)}}\lambda(n)\lambda(n+2)\Bigr|
>   \;\le\;\Bigl(\tfrac12\bigl(1-\tfrac2p\bigr)-2\bigl(\min(\delta_1,\delta_2)-\tfrac1{2p}\bigr)\Bigr)x .
> \]
> The index set is a union of **p − 2 residue classes mod 2p**; for p ≥ 5 it is **not** a union of
> classes mod 1 or mod 2. **Corollary.** If MR's sign-change proportion is bounded below by an
> absolute δ₀ > 0 uniformly over the two families {f₁^{(p)}}, {f₂^{(p)}}, then for every prime
> p > 1/(2δ₀) the reachable modulus set at shift 2 **strictly contains {1,2}**.
